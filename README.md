## 1. Project Overview

This project contains 10 Python programming case studies designed to develop problem-solving, logical thinking, and programming skills.

Each case study focuses on a real-world problem and demonstrates the application of Python programming concepts through algorithms, pseudocode, flowcharts, program implementation, test cases, and outputs.

The project is organized to make the source code, documentation, and execution results easy to understand and review.

## 2. Objectives

- To develop logical and computational thinking.
- To understand and implement algorithms and pseudocode.
- To represent program logic using flowcharts.
- To implement solutions using Python.
- To test programs with appropriate test cases.
- To document program outputs and results.
- To apply Python concepts to real-world problems.

## 7. How to Run the Python Programs

### Prerequisites

- Install Python 3 on your computer.
- Download or clone this repository.
- Extract the ZIP file if you downloaded the project as a ZIP archive.

### Execution Steps

1. Open the project folder in Visual Studio Code or a terminal.
2. Navigate to the `programs` folder.
3. Select the Python program you want to execute.
4. Run the program using the command below, replacing the filename with the program you want to run.

```bash
python case12_attendance_recovery.py
```

If your system uses the `py` launcher on Windows, you can also run:

```bash
py case12_attendance_recovery.py
```

Repeat the process for the other Python programs.
